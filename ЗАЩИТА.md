# Демонстрация проекта за 3 минуты

## Что показать

1. `npm run dev`, открыть http://127.0.0.1:3000.
2. Написать **«Покажи расписание 11-401»** — появится карточка с парами.
3. Переключить день недели и группу. Показать время, аудиторию и исходные пометки.
4. Показать в журнале справа реальный MCP-вызов `get_group_schedule`.
5. Если подключён OpenRouter: спросить **«Как связаться с ИТИС?»** и показать поиск,
   чтение страницы и ответ модели со ссылками.

## Что объяснить

«Мы реализовали MCP-сервер с тремя инструментами: поиск по КФУ, чтение страницы
и расписание группы. Наше приложение подключается к нему официальным MCP-клиентом
через stdio / JSON-RPC. Для общих вопросов модель через OpenRouter выбирает инструменты
и формирует ответ по источникам. Для расписания есть быстрый маршрут без LLM:
он определяет группу и день, вызывает тот же MCP-инструмент и рисует карточки
из структурированных данных. Это работает без API-ключа и без интернета».

## Откуда расписание

Сохранённая копия предоставленной Google-таблицы — `server/data/timetable.json`.
В карточке указана дата получения. Обновить в памяти можно кнопкой в интерфейсе,
а встроенную копию на диске — командой `npm run schedule:update`.
Парсер ExcelJS учитывает объединённые ячейки общих лекций.

## Честные ограничения

- Это шаблон недели, а не календарь с автоматически вычисленными отменами и каникулами.
- Условия по чётности и подгруппам сохранены в исходном тексте пары.
- Готовая модель используется через API, собственного обучения нет.
- Поиск по КФУ лексический и ограничен доступными HTML-страницами; PDF не читаются.
- Карточка расписания рисуется программно, поэтому модель не может изменить её аудитории.

## Где смотреть код

- `server/mcp-server.mjs`: регистрация инструментов и stdio-транспорт.
- `server/agent.mjs`: цикл LLM → инструмент → результат → LLM.
- `server/schedule-request.mjs`: прямой маршрут расписания через MCP.
- `server/schedule.mjs`: чтение таблицы и работа с объединёнными ячейками.
- `components/schedule-card.tsx`: интерактивное отображение занятий.
