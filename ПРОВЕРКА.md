# Проверка проекта

Проверено при завершении реализации карточки расписания:

- `npm test`: 13 тестов прошли — обработка URL/HTML, цикл агента, ошибки, HTTP-заголовки,
  объединённые ячейки, разделение групп, дни недели и московские даты,
  маршрутизация запросов и структурированный ответ MCP.
- `npx tsc --noEmit`: проверка типов прошла.
- `npm run build`: сборка интерфейса прошла.
- Страница `/` возвращает HTTP 200.
- Настоящий локальный `/api/schedule`: группа 11-401, понедельник, структурированные занятия.
- Настоящий `/api/chat`: «Покажи расписание 11-401 на завтра» вызывает MCP-инструмент
  и возвращает объект расписания для карточки. LLM для этого маршрута не используется.
- Предыдущая проверка OpenRouter: вопрос о контактах ИТИС → поиск → чтение страницы → ответ со ссылкой.

Браузерное визуальное тестирование текущей версии не выполнено: браузер недоступен инструменту управления.
Сборка и проверки API не являются оценкой точности всех общих ответов модели.
